# M13H Validation Localization Report

## Problem

Validation UX relied on `validation_fallback_messages.dart` for all user-visible strings, bypassing `AppLocalizations` even where delegates were already wired.

## Scope

- No backend validation rule changes.
- No `ValidationIssue` shape changes.
- No behavioral changes to protected-action routing, publish gate logic, or media upload protocols.
- English fallback map retained; dynamic lookup uses a generated switch/map pattern (no reflection).

## Localization Resolver

New module: `lib/core/validation/localized_validation_messages.dart`.

- `validationMessageKeyLocalized(BuildContext, String messageKey, {params})`
- `validationIssueDisplayMessageLocalized(BuildContext, ValidationIssue)`
- `validationFieldLabelLocalized` — localized counterpart of `validationFieldLabelForPublish`.
- `learnModuleLabelLocalized` — module short labels for `learn.module.notCompleted`.
- Unknown key: English fallback template if present, else constant `validationUnknownFieldMessage` (`"Please check this field."`).

Resolver body for keys is generated by `tool/gen_localized_validation_resolver.dart` from `validation_fallback_messages.dart`.

## ARB Keys Added

- Template `app_en.arb` built via `tool/build_app_en_arb.dart` from the fallback map plus publish-sheet chrome, CTAs, field labels, media generic strings, module-completion template, and reserved `learn.furigana.*` entries.
- `app_ja.arb` / `app_my.arb` synced with `tool/mirror_arb_locales.dart` (English mirror for new keys; existing Japanese settings strings preserved).

## UI Surfaces Updated

- `publish_validation_sheet.dart` — localized titles, sections, buttons, issue text.
- `protected_action.dart` / `protected_action_guard.dart` — localized prompt body and snackbar.
- Auth login/register — field issues as `ValidationIssue` + localized display.
- Edit profile — `ValidationIssue` map, banner issue, localized media upload via stored error object.
- Create story basics form — inline errors from localized issues.
- Add-to-collection sheet + profile collection rename — localized validation messages.
- Create / creator basics / audio editor — `validationMessageKeyLocalized` + `mediaUploadUserMessageLocalized`; `coverUploadFailureInlineHintLocalized` in `story_basics_cover_upload_outcome.dart`.

## Fallback Policy

1. Try `AppLocalizations` for known `messageKey`.
2. On miss or exception, use `validationFallbackMessagesEn` + `interpolateValidationFallback`.
3. If still unknown, `validationUnknownFieldMessage`.

## Interpolation

Parameterized keys (`story.sentences.tooFew`, `learn.count.*.range`, etc.) use ARB placeholders (`min`, `max`, `actual`). Params passed but missing from template still interpolate via English fallback path.

**Remaining risk:** Some validators attach extra params (e.g. `learn.vocab.meaning.length`) while the English template has no `{placeholder}` tokens; l10n strings match the legacy fixed English. Full per-param sentences can be added to ARB later without changing `messageKey`.
